# Unidade VII — Gabarito da múltipla escolha

| Questão | Resposta | Justificativa |
|---|---|---|
| U07-M01 | A | A raridade depende de uma condição contextual. Valor alto ou grupo unitário não define o tipo, e a causa ainda não foi confirmada. |
| U07-M02 | C | A anomalia coletiva emerge da relação entre elementos de uma sequência ou conjunto. |
| U07-M03 | B | O detector identifica desvio da referência; fraude é uma hipótese causal que requer evidência adicional. |
| U07-M04 | D | O desvio-padrão coloca a diferença em unidades de dispersão da referência. |
| U07-M05 | A | Extremos podem deslocar média e ampliar desvio-padrão, mascarando o próprio afastamento. |
| U07-M06 | B | A cerca superior é $Q_3+1{,}5IQR$, com $IQR=Q_3-Q_1$. |
| U07-M07 | C | MAD é a mediana de $|x_i-\tilde{x}|$. |
| U07-M08 | D | MAD zero torna a divisão indefinida; empates, janela e método precisam ser revistos. |
| U07-M09 | A | Um $k$ maior usa escala de vizinhança mais ampla e tende a suavizar detalhes locais. |
| U07-M10 | B | LOF próximo de 1 indica densidade semelhante à vizinhança, não confirmação de normalidade absoluta. |
| U07-M11 | C | A comparação local permite distinguir um ponto típico de uma região esparsa de uma quebra em região densa. |
| U07-M12 | D | `-1` é ruído segundo os parâmetros do DBSCAN, não rótulo causal ou erro confirmado. |
| U07-M13 | A | Raridade populacional pode ser legítima; tamanho pequeno não prova erro. |
| U07-M14 | B | Precisão@10 é a fração confirmada entre os dez casos priorizados. |
| U07-M15 | C | A disponibilidade do rótulo depende da seleção feita pelo detector. |
| U07-M16 | D | Revisão contextual, registro e contestação separam alerta de decisão e reduzem dano indevido. |
| U07-M17 | C | Uma combinação pode ser rara na distribuição conjunta mesmo quando os valores marginais são comuns. |
